# 🧮 Calculadora Android

Aplicación de calculadora desarrollada en **Kotlin con Android Studio**.

Este proyecto fue realizado como actividad evaluable del módulo **Programación Multimedia y Dispositivos Móviles**, del Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM).

## 💻 Tecnologías utilizadas

- Kotlin
- Android Studio
- XML
- Gradle

## 📱 Funcionalidades

### ➕ Calculadora básica
- Suma, resta, multiplicación y división.
- Operaciones matemáticas básicas.
- Interfaz adaptada a la orientación vertical.

### 🔬 Calculadora científica
- Funciones matemáticas avanzadas.
- Interfaz adaptada a la orientación horizontal.
- Cambio de diseño según la orientación del dispositivo.

## 🎯 Objetivo del proyecto

Aprender a desarrollar aplicaciones Android, gestionar eventos y adaptar las interfaces gráficas a diferentes orientaciones de pantalla.

## 🚀 Ejecución

1. Abrir el proyecto en Android Studio.
2. Esperar a que Gradle sincronice.
3. Ejecutar la aplicación en un emulador o dispositivo Android.
